# Tablet Error in the FOVS Method

This repository contains the code, simulation outputs, and report for a project investigating how tablet-dose variation affects the precision of microfossil absolute-abundance estimates using the FOVS method.

## Files

- `sims_Fossil.R`: generates the simulated data.
- `analysis_Fossil.R`: summarizes the results and produces the figures and tables.
- `simulation_outputs/`: contains the saved simulation results.
- `Report_Fu_M.pdf`: the final project report.
